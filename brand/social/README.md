# Identité sociale SANDBOX

`sandbox-social-avatar.png` est la déclinaison carrée commune aux réseaux sociaux du logotype officiel `logov2.png`. Elle conserve le mot-symbole SANDBOX et son A cyan, sur le fond bleu nuit de la charte DD-0002, avec le contenu dans une zone sûre pour le recadrage circulaire. Le même fichier est utilisé comme avatar sur Instagram, TikTok et X.

Instagram n'affiche pas de bannière de profil. Le nom public `Sandbox TalkShow` et la bio restent renseignés sur `@sandbox.talkshow`. L'identifiant Instagram a été modifié depuis `@sandbox.podcast.pro` le 17 octobre 2026. Cet avatar est appliqué aux profils Instagram `@sandbox.talkshow`, TikTok `@sandbox.talkshow` et X `@SandboxTalkShow`, puis vérifié le 17 octobre 2026. Les stories à la une pourront recevoir des couvertures assorties quand ces rubriques auront du contenu réel.
