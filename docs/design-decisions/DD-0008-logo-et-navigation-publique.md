# DD-0008 — Logo et navigation publique

- Date : 2026-10-08
- Statut : accepté
- Décision de Lou, à partir des captures du header et du footer.
- Remplace, pour le site public, les dispositions sur le choix de thème de DD-0003 et DD-0005.

## Décision

Le logotype complet `logov2.png` fourni à la racine du dépôt remplace l'ancien pictogramme et le nom Sandbox recréé en texte dans l'en-tête et le pied de page. L'application en sert une copie sous `apps/site/public/sandbox-logo.png`. Aucun descriptif n'est affiché sous ce logo, dans l'en-tête comme dans le pied de page.

Le choix de thème disparaît de toutes les pages. La charte bleu nuit et cyan reste l'unique apparence publique ; une ancienne préférence rouge enregistrée dans le navigateur n'est plus appliquée. Le changement de langue reste visible dans l'en-tête de toutes les pages publiques. Lorsque la page courante n'a pas d'équivalent publié dans l'autre langue, le lien mène à son accueil ou à son index de classements existant.

Le bloc « Envie d'explorer ? » est retiré de l'accueil. Le menu Podcasts ouvre les liens vers tous les épisodes et les thèmes, au clavier comme au toucher. La rubrique Classements et la recherche gardent leurs accès dans l'en-tête ; la recherche, les thèmes et le flux RSS restent accessibles dans le pied de page.

Dans les autres langues, les deux liens du menu Podcasts indiquent « (FR) » tant que ces pages ne sont disponibles qu'en français.

## Portée

La décision touche la présentation et la navigation publiques. Elle ne change aucun contenu éditorial, classement, compte ni donnée de production. Les langues non encore traduites restent soumises à la revue prévue par ADR-0020 ; la présence du contrôle de langue ne leur donne pas un statut publié.
