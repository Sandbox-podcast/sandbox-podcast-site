# DD-0065 : nom public Sandbox Podcast sur les profils

Date : 2026-10-20. Décision demandée par Lou.

Les profils publics utilisent le nom d'affichage `Sandbox Podcast`, cohérent avec le domaine sandboxpodcast.fr. Le mot-clé `Talkshow` apparaît dans leurs descriptions. Les identifiants et les URL des comptes restent inchangés.

Cette décision remplace DD-0054 pour les profils publics YouTube, Instagram, TikTok, X, LinkedIn et Spotify. Le compte Spotify visé est l'émission publiée `2Wp6S4qgRqQaV01AjkDcMH`.

## État vérifié le 20 octobre

- YouTube `@SandboxFR`, Instagram `@sandbox.talkshow`, TikTok `@sandbox.talkshow`, X `@SandboxTalkShow` et Spotify affichent `Sandbox TalkShow`.
- LinkedIn affiche déjà `Sandbox Podcast`. La description de la page est vide.
- TikTok bloque le changement du nom jusqu'au 24 octobre. Sa bio actuelle utilise 75 caractères sur 80 pour trois liens.

Les textes préparés et les limites de chaque plateforme sont dans [les profils et descriptions du 20 octobre](https://github.com/Sandbox-podcast/sandbox-podcast-resources/blob/main/docs/site/history/2026/10/social-profile-copy-2026-10-20.md). La sauvegarde des profils publics reste à confirmer au moment de l'action.
