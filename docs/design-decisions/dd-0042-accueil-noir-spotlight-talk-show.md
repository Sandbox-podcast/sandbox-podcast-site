# DD-0042 : accueil noir, carrousel des projets et Talk Show

Date : 2026-10-16. Décision : décidée par l'agent sur délégation (PD-0003), à la demande de Lou.

La suite du plateau adopte un fond noir neutre, des textes blancs et gris et les accents cyan Sandbox. Le panneau vert arrondi des projets disparaît. Les animateurs, les projets, les rubriques et le dernier épisode partagent ce fond, avec des séparateurs discrets. Le plateau desktop et ses trois easter eggs restent en place. Le mobile conserve son accueil typographique et l'entrée séparée du vidéoclub, sans montage des animateurs dans le décor.

Les trois projets sélectionnés, Okodukai, Song Maker et Sillage, deviennent un carrousel manuel inspiré de la démonstration publique Spotlight Carousel de Scrolltide : https://www.scrolltide.co/components#c-spotlight-carousel. Le projet central ouvre son cadre et affiche sa légende, tandis que les deux autres restent en retrait. Les images se recadrent sans déformation. Aucun code payant ni dépendance supplémentaire n'est importé.

Les flèches, les trois boutons de sélection, les touches gauche/droite et Home/End, ainsi que le glissement horizontal permettent de changer de projet. Seul le lien du projet actif entre dans l'ordre de tabulation. Le carrousel n'avance jamais automatiquement. Les liens gardent leur destination native. Les transitions s'effacent avec la préférence de réduction des mouvements.

Song Maker reçoit une couverture de concept qui représente un atelier musical. Sillage utilise l'image fournie par Lou dans sa correction du 16 octobre. Les captures réelles du catalogue restent dans leurs fiches. Les visuels locaux WebP pèsent chacun moins de 300 Ko ; leur provenance est consignée dans le dossier du site.

La désignation publique de Sandbox devient Talk Show dans la navigation, les pages, les métadonnées, la recherche, le pied de page, les contenus par défaut et les trois traductions. Les URL, identifiants techniques, adresses de contact, la marque Apple Podcasts et les types Schema.org gardent leurs valeurs pour préserver les liens existants et les contrats techniques.

Ce lot reste local. Aucune nouvelle PR, publication, commit ou push n'est compris dans cette décision.
