# Sources examinées pour les classements

État au 2026-10-12. Une ligne de ce tableau désigne un fournisseur ou un jeu de mesures, pas nécessairement un avis indépendant. Les sources marquées "contexte" ne pèsent pas sur le score principal. Voir [ADR-0023](../adr/ADR-0023-classements-corrobores.md) pour les poids et les seuils.

| Source                                                                                                       | Usage retenu                                                   | Limite ou décision                                                                                                                                                                                 |
| ------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [GitHub API](https://docs.github.com/en/rest/repos/repos#get-a-repository)                                   | Score d'activité des dépôts et croissance des stars des skills | Stars et forks mesurent l'attention, pas la qualité du code.                                                                                                                                       |
| [OpenSSF Scorecard API](https://api.scorecard.dev/)                                                          | Second avis des dépôts, fondé sur neuf contrôles de pratiques  | Au moins six contrôles et un rapport de quatorze jours au plus; aucun label de sûreté.                                                                                                             |
| [Skills.sh API](https://www.skills.sh/docs/api)                                                              | Installations des skills sur sept jours                        | Télémétrie des installations du CLI; ne mesure ni exécution ni résultat obtenu.                                                                                                                    |
| [Arena Leaderboard Dataset](https://huggingface.co/datasets/lmarena-ai/leaderboard-dataset)                  | Préférences humaines pour Models, Coding et Agents             | Seuil de votes ou d'observations; seules les lignes récentes de la vue `latest` sont retenues.                                                                                                     |
| [Artificial Analysis via OpenRouter](https://openrouter.ai/docs/api/api-reference/benchmarks/get-benchmarks) | Second évaluateur de Models, Coding et Agents                  | Même transport API qu'OpenRouter, mais mesures produites par un autre évaluateur; `meta.as_of` est contrôlé.                                                                                       |
| [Hugging Face Hub API](https://huggingface.co/docs/hub/api)                                                  | Téléchargements, licence et accès des modèles                  | Signal de portée et d'identité, jamais preuve de qualité.                                                                                                                                          |
| [OpenRouter Models API](https://openrouter.ai/docs/api/api-reference/models/get-models)                      | Usage, prix, contexte et débit des modèles                     | Ces données ne sont pas un second benchmark de qualité. Prix et débit dépendent du fournisseur.                                                                                                    |
| [OSS Insight Public API](https://ossinsight.io/docs/api)                                                     | Étudiée pour découvrir des dépôts                              | Redérive les événements GitHub et ne constitue pas un avis indépendant. Une [panne publique de l'API](https://github.com/pingcap/ossinsight/issues/3088) a aussi été signalée. Aucune pondération. |
| [SkillsMP API](https://skillsmp.com/docs/api)                                                                | Étudiée pour élargir le pool Skills                            | Recherche par mot clé, sans parcours complet du catalogue; le tri par stars redérive GitHub. Aucune pondération.                                                                                   |
| [LiveBench](https://github.com/LiveBench/new-livebench)                                                      | Benchmark étudié pour Models                                   | Fichiers CSV publics, mais noms des variantes avec effort et configuration différents; rapprochement exact avec nos identités non garanti. Aucune pondération.                                     |
| [SWE-bench](https://github.com/SWE-bench/swe-bench.github.io)                                                | Benchmark étudié pour Coding                                   | La plupart des lignes mesurent un système agent plus modèle. Le sous-classement à agent fixe demanderait un rapprochement et une validation propres. Aucune pondération.                           |

La présence de onze sources examinées ne signifie pas onze votes dans une moyenne. GitHub et OSS Insight partageraient les mêmes événements; Hugging Face Hub et OpenRouter mesurent surtout la portée et le prix. Le rang principal utilise seulement des mesures comparables et correctement reliées à la même entité. Une source absente laisse le rang en attente si elle est requise.
