# Site média SANDBOX

Le site SANDBOX publie les épisodes du podcast et des classements tech et IA. L’application Next.js du site est dans apps/site.

## Lire les classements

Les éditions publiées associent des relevés datés, des scores et une version de méthodologie. Les anciens snapshots présents dans le dépôt illustrent le format. Pour interpréter un classement, consulter la méthode correspondant à son édition.
